# 지역별 인구구조 분석 및 유사 지역 탐색 웹앱

주민등록 연령별 인구현황 데이터를 활용하여, 사용자가 선택한 지역의 연령별 인구구조를 시각화하고 전국에서 인구구조가 가장 유사한 지역을 탐색하는 Streamlit 웹앱입니다.

본 프로젝트는 `2026년 8월 주민등록 연령별 인구현황` CSV 데이터를 기반으로 하며, 시·도, 시·군·구, 읍·면·동 단위까지 분석할 수 있도록 구성했습니다.

---

## 주요 기능

### 1. 지역 검색 및 선택

사용자가 지역명을 직접 입력하여 검색한 뒤, 검색 결과에서 원하는 지역을 선택할 수 있습니다.

예:

```text
서울
종로구
강남구
청운효자동
수원시
```

시·도뿐 아니라 읍·면·동 단위 지역도 선택할 수 있습니다.

---

### 2. 선택 지역의 인구 현황 확인

선택한 지역에 대해 다음 정보를 확인할 수 있습니다.

* 총인구
* 남성 인구
* 여성 인구
* 성비
* 유소년 인구
* 생산연령 인구
* 고령 인구

연령집단은 다음과 같이 구분합니다.

| 구분      | 연령     |
| ------- | ------ |
| 유소년 인구  | 0~14세  |
| 생산연령 인구 | 15~64세 |
| 고령 인구   | 65세 이상 |

---

## 3. 연령별 인구구조 시각화

Plotly를 활용하여 선택 지역의 연령별 인구구조를 인터랙티브 꺾은선 그래프로 시각화합니다.

그래프에서는 다음 항목을 선택적으로 표시할 수 있습니다.

* 전체 인구
* 남성 인구
* 여성 인구

또한 연령 범위를 조절하여 원하는 연령대만 확인할 수 있습니다.

예:

```text
0세 ~ 100세 이상
20세 ~ 40세
65세 ~ 100세 이상
```

Plotly 그래프이므로 마우스를 올리면 해당 연령의 정확한 인구수를 확인할 수 있습니다.

---

## 4. 전국 인구구조 유사 지역 TOP 5

사용자가 선택한 지역과 연령별 인구구조가 가장 유사한 전국 지역 5곳을 자동으로 탐색합니다.

단순히 총인구가 비슷한 지역을 찾는 것이 아니라, 각 지역의 연령별 인구 비율을 기준으로 비교합니다.

예를 들어 다음과 같이 총인구 규모가 크게 달라도 연령구조가 유사하다면 높은 유사도를 가질 수 있습니다.

```text
A지역 총인구: 50,000명
B지역 총인구: 5,000명
```

두 지역의 연령별 인구비율이 비슷하다면 인구구조가 유사한 지역으로 판단합니다.

---

# 인구구조 유사도 계산 방법

## 1. 연령별 인구비율 계산

각 지역의 0세부터 100세 이상까지의 인구를 전체 인구로 나누어 비율로 변환합니다.

예를 들어 총인구가 10,000명이고 30세 인구가 200명이라면,

```text
30세 인구비율
= 200 / 10,000
= 0.02
= 2%
```

이 과정을 모든 연령에 대해 수행합니다.

따라서 하나의 지역은 다음과 같은 101차원의 연령분포 벡터로 표현됩니다.

```text
[0세 비율,
 1세 비율,
 2세 비율,
 ...
 99세 비율,
 100세 이상 비율]
```

---

## 2. 코사인 유사도

지역 간 인구구조 유사성은 코사인 유사도(Cosine Similarity)를 이용하여 계산합니다.

코사인 유사도는 두 벡터의 방향이 얼마나 유사한지를 측정하는 방법입니다.

수식은 다음과 같습니다.

```text
Cosine Similarity(A, B)

= (A · B) / (||A|| × ||B||)
```

값이 1에 가까울수록 두 지역의 연령별 인구구조가 유사합니다.

웹앱에서는 이를 백분율 형태로 표시합니다.

예:

```text
99.85%
99.42%
98.97%
```

---

## 3. TOP 5 지역 선정

전국 모든 지역에 대해 선택 지역과 코사인 유사도를 계산한 뒤,

```text
1. 선택 지역 자체 제외
2. 총인구가 0인 지역 제외
3. 유사도 내림차순 정렬
4. 상위 5개 지역 선택
```

과정을 거쳐 가장 유사한 지역 TOP 5를 선정합니다.

---

# 유사 지역 비교 그래프

선택 지역과 유사 지역 TOP 5의 연령별 인구비율을 하나의 Plotly 그래프에서 비교할 수 있습니다.

그래프의 Y축은 단순 인구수가 아니라 각 지역의 전체 인구에서 해당 연령이 차지하는 비율입니다.

```text
Y축 = 해당 연령 인구 / 지역 전체 인구 × 100
```

따라서 인구 규모가 서로 다른 지역도 직접 비교할 수 있습니다.

선택 지역은 상대적으로 굵은 선으로 표시하고, 유사 지역 TOP 5를 함께 표시합니다.

# 유사도 막대그래프

선택 지역과 TOP 5 지역 간의 코사인 유사도를 별도의 가로 막대그래프로 표시합니다.

예:

```text

지역 C  ██████████████████    99.42%
지역 D  █████████████████     99.21%

```

이를 통해 어떤 지역이 선택 지역과 가장 유사한지 쉽게 확인할 수 있습니다.

# 데이터 전처리

원자료의 일부 숫자는 다음과 같이 쉼표가 포함된 문자열 형태입니다.

```text
9,281,625
48,523
10,592
```

따라서 분석 전에 쉼표를 제거하고 숫자형으로 변환합니다.

```python
df[column] = (
    df[column]
    .astype(str)
    .str.replace(",", "", regex=False)
)

df[column] = pd.to_numeric(
    df[column],
    errors="coerce"
).fillna(0)
```

# 한글 파일명 문제 대응

Mac 환경에서는 한글 파일명이 NFC/NFD Unicode 형식 차이로 인해 Streamlit Cloud에서 파일을 찾지 못하는 문제가 발생할 수 있습니다.

이를 방지하기 위해 `unicodedata.normalize()`를 사용합니다.

```python
unicodedata.normalize(
    "NFC",
    file_name
)
```

또한 현재 실행 위치가 아닌 `app.py` 파일이 실제 존재하는 경로를 기준으로 데이터 파일을 탐색합니다.

```python
BASE_DIR = os.path.dirname(
    os.path.abspath(__file__)
)
```

# 분석 시 유의사항

## 코사인 유사도의 특성

전국 지역은 어느 정도 공통적인 연령분포 구조를 가지고 있기 때문에 코사인 유사도가 매우 높게 나타날 수 있습니다.

예를 들어 상위 지역들이 모두 다음과 같이 나타날 수 있습니다.

```text
99.8%
99.7%
99.6%
99.5%
99.4%
```

이는 반드시 오류를 의미하지 않습니다.

코사인 유사도는 절대적인 차이보다는 두 연령분포 벡터의 형태와 방향이 얼마나 유사한지 측정하기 때문입니다.

따라서 향후 더 민감한 인구구조 차이 분석을 위해 다음 방법을 추가할 수 있습니다.

* Jensen-Shannon Distance
* Euclidean Distance
* Manhattan Distance
* 연령대별 가중 거리
* PCA 기반 지역 군집화
* K-means Clustering
